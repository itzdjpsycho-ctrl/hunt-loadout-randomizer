Tools

From Hunt: Showdown 1896 Wiki
Jump to navigation Jump to search

Tools make up the core utility of a Hunter's loadout. Some Tools are unlocked at the start, while the rest are unlocked through Bloodline progression. Some Tools can only be used a set amount of times, which can be extended with the Frontiersman Trait.

In Bounty Hunt and Bounty Clash, players equip a Hunter with their desired loadout of Tools, Weapons, and Consumables before the match, then spawn in with them.
In Soul Survivor, players have to search the map for Tools to equip and utilize.

You can alphabetically see all Tools by visiting the Tools Category.

Tool Statistics

Tool Stats of the Choke Bombs

Tool Stats quantify the qualities of each Tool. Unlike weapons, these stats are hardly modified, except for the Pitcher trait extending Throw Range.

Some Tools such as the Flare Pistol and Quad Derringer utilize Weapon Stats rather than Tool stats.

Damage

  • Damage value of a tool hitting a Hunter with its full effect.
  • For throwables, damage of a tool hitting a Hunter in the upper torso

Damage per Tick

  • Damage while affected by a tool

Drop Range

  • Distance (in meters) at which a projectile drops roughly a head's height (20cm) below the aim point

Effect Duration

  • The time a tool effect lasts in seconds.

Effect Radius

  • Effect radius in meters.

Fuse Timer

  • The time (in seconds) until a tool detonates

Muzzle Velocity

  • The velocity (meters per second) at which a weapon's projectile travels
  • Projectiles travel in a ballistic arc

Spread

  • The relative crosshair spread of a weapon while aiming from the hip

Throw Range

  • The furthest range (in meters) a tool can be thrown.

Melee Damage

  • Damage value of a light or heavy melee attack that hits a Hunter in the upper torso

Stamina Consumption

  • The stamina consumed (out of 100) with a light melee attack, heavy melee attack, or when thrown
