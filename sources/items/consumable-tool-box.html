Description

A portable toolkit that refills some dwindling supplies in a tight spot.

Information

  • The Tool Box has the same item pool as the world Tool Box and grants the player one spent Tool.

Recommended Traits

The Tool Box can use the following Traits:

  • Packmule - Receive an additional tool or consumable when looting players or opening item boxes.

Use Tips

The Tool Box can help restock some tools and taking Packmule helps make it much more worthwhile as you will gain an additional tool.

Book of Weapons

TOOL BOX. (See also, STORAGE CONTAINERS) An easily portable container, first developed by carpenters and then adapted by the US military, that is equipped with a variety of useful tools. The primary challenge to overcome was balancing the portability and safety of the box, considering the range of volatile items being carried. This rough but functional creation is an impressive achievement of technology, and the result of many lessons learned from many accidents.
