Description

Scottfield made, single-action top-break revolver. Performs well at medium range and can be reloaded quickly when empty. Modified with an added stock.

Recommended Traits

The Scottfield can use the following Traits:

  • Fanning - Faster rate of fire when using one-handed or two-handed single-action pistols.
  • Quartermaster - Gain +1 Weapon Capacity
